# 原神角色 𝕏 圖片搜尋

<img width="1896" height="822" alt="網站首頁：依元素篩選、點選原神角色" src="https://github.com/user-attachments/assets/b37932be-5032-49b9-af59-3a2eb4a2c8f3" />

**網站：https://twl-benchen.github.io/genshin-impact-search/**

點選原神角色，一鍵產生 𝕏（Twitter）hashtag 搜尋網址，到 𝕏 上找角色的同人圖。另外也提供「圖片合併下載」：把 𝕏 上被拆成好幾張發的圖合併成一張，或把 𝕏 的 GIF 存成 GIF／MP4。

- 純靜態網頁，不需要註冊，也沒有後端伺服器。
- 圖片與影片都在你的瀏覽器裡處理，**不會上傳到任何地方**。
- 電腦、手機都能用；Android 可以安裝成 App，從 𝕏 App 直接分享過來。

## 角色 hashtag 搜尋（首頁）

### 怎麼用

1. （可選）點上方的元素圖示篩選角色；再點一次同一個元素就恢復顯示全部。
2. 點選想找的角色，可以選很多個。已選的角色會出現在畫面底部的操作列，點頭像就能移除。
3. 按「前往𝕏頁面」，就會在新分頁開啟 𝕏 的搜尋結果（**需要登入 𝕏 帳號**才看得到搜尋結果）。
   - 也可以按「複製網址」把搜尋網址貼到別的地方，或按「清空」重新選。

選取的角色會記在網址裡（例如 `#c=Klee,Nahida&e=Pyro`），把網址存成書籤或分享給朋友，打開時會是同樣的選擇。

### 設定（右上角齒輪）

| 設定 | 選項 | 說明 |
|---|---|---|
| 搜尋邏輯 | AND／OR | **AND**：所有選的角色同時出現（例如找兩人的 CP 圖）。**OR**：任一角色出現就算。 |
| 搜尋語言 | 英文／日文／繁中／簡中（可複選） | 每個角色會用所選語言的 tag 一起搜，例如 `(#Klee OR #クレー OR #可莉)`。所選語言都沒有 tag 時會退回英文。 |
| 結果類型 | 全部／圖片與影片／只有圖片／只有影片 | 對應 𝕏 的 `filter:media`、`filter:images`、`filter:videos`。 |
| 排序 | 熱門／最新／媒體分頁 | 開啟 𝕏 搜尋時要停在哪一頁。 |
| 日期範圍 | 不限／7 天／30 天／一年／自訂 | 對應 `since:`、`until:`；自訂的結束日期會包含當天。 |
| 熱門度門檻 | 不限／100+／500+／1000+ 讚 | 對應 `min_faves:`，只看比較多人按讚的圖。 |
| 進階搜尋 | 開／關 | 有些角色名稱是很常見的字（例如「琴」「北斗」「ジン」），直接搜會混進不相關的貼文。開啟後這些 tag 會加上 `#原神` 限定，例如 `(#琴 #原神)`。 |

- 轉推一律排除（`-filter:retweets`），避免同一張圖重複出現。
- 設定只保留到分頁關閉：跳去 𝕏 再回來、重新整理都還在；開新分頁或下次再來會回到預設值。

## 圖片合併下載（merge.html）
<img width="1493" height="826" alt="image" src="https://github.com/user-attachments/assets/fd267ab7-3a90-45e3-98d8-cb1284ad6706" />

**網址：https://twl-benchen.github.io/genshin-impact-search/merge.html （首頁左上角的按鈕也能進入）**

使用情境：在 𝕏 上看到一張圖被拆成好幾張發、或是 GIF 想存下來時，複製貼文連結，回到這裡貼上。

頁面分成「**圖片**」「**影片**」兩個分頁，最上方的貼連結框兩個分頁共用：

### 貼 𝕏 貼文連結

- 貼上連結就會**自動開始抓取**，不用按按鈕；手動輸入時按 Enter（Shift+Enter 換行）。在頁面任何地方直接貼上連結也可以。
- 可以一次貼好幾篇（換行、空白分隔都行），會依貼上的順序加入。
- 圖片會放進「圖片」分頁、GIF／影片會放進「影片」分頁；只有其中一種時會自動切到那個分頁，兩種都有時看分頁上的數字。
- 支援的連結格式：`x.com`、`twitter.com`、`mobile.twitter.com`、`fxtwitter.com`、`vxtwitter.com`、`fixupx.com`、`fixvx.com`，包含 `/i/status/…`、後面帶 `?s=20`、`/photo/2` 的網址。
- 會抓**原圖**（最高畫質）。
- 抓不到時會說明原因：貼文不存在或已刪除、私人帳號、這篇沒有圖片、服務暫時無法使用等。

### 圖片分頁：合併成一張

1. **加入圖片**：貼連結抓到的圖會自動加入；也可以「選擇圖片」、把圖片拖進頁面，或按 Ctrl+V 貼上。
2. **調整順序**：拖曳縮圖排序（手機長按後拖），或用縮圖下方的 ◀ ▶；× 刪除單張，「全部清除」清空。
3. **合併設定**：

   | 設定 | 選項 |
   |---|---|
   | 拼接方向 | 橫式（左右，預設）／直式（上下）／**2×2**（剛好 4 張時才會出現，第 1、2 張一列，第 3、4 張一列） |
   | 尺寸不同時 | 放大（以最大的那張為準，保留細節）／縮小（以最小的那張為準，檔案較小）；其他圖片會等比縮放對齊 |
   | 間距 | 0–100 px |
   | 背景色 | 白、米白、黑、透明（只有 PNG）、自訂顏色；用在間距與空白處 |
   | 輸出格式 | PNG（無損）／JPG（檔案小，可調品質） |

4. **預覽與下載**：即時預覽合併結果，按「下載圖片」。來自 𝕏 的圖檔名會是 `作者_貼文ID_merged.png`。
   - 手機上另有「分享／存到相簿」按鈕（iPhone 用「下載」會存到「檔案」，用這個才能直接存到「照片」）。

> 圖片太大時：每個瀏覽器能處理的圖片大小有上限（iPhone／iPad 約 4096×4096 的面積），超過時會**自動縮小**並告訴你原本和縮小後的尺寸。想要更大的尺寸可以改用電腦。

### 影片分頁：GIF／MP4 下載

𝕏 上的「GIF」其實是 MP4 影片。每支影片都可以：

- **下載 MP4**：直接存原始影片，檔案最小、畫質最好。
- **轉成 GIF**：在瀏覽器裡逐格轉成 GIF，有進度條，可以取消。
  - **GIF 幀率**：原始（預設）／30／20／15／10。「原始」會讀取影片本身的幀率（GIF 最高 50 fps）。
  - **GIF 寬度**：原始（預設）／480／320／240，不會超過影片原本的寬度。
  - 幀率、寬度越高，GIF 越流暢但檔案越大；影片超過 20 秒時會提醒，非常長的影片轉檔前會先確認。

## 安裝成 App、Android 分享直達

### Android

1. 用 Chrome 或 Samsung Internet 開啟網站，從瀏覽器選單選「**安裝應用程式**」或「**加到主畫面**」。
2. 之後在 𝕏 App 看到想存的貼文，按「**分享**」→ 選「**原神𝕏搜尋**」。
3. 會直接開啟圖片合併頁並自動抓取那篇貼文的圖片或 GIF。

### iPhone／iPad

可以用 Safari 的「分享 → 加入主畫面」把網站放到主畫面，但 iOS 不支援「從其他 App 分享過來」，所以請用「複製連結 → 回到網站貼上」的方式。

## 常見問題

**需要登入嗎？**
搜尋功能本身不需要，但 𝕏 的搜尋結果頁要登入 𝕏 才看得到。圖片合併、GIF 下載不需要登入。

**我的圖片會被上傳嗎？**
不會。合併、轉 GIF 都在你的瀏覽器裡完成。貼 𝕏 連結時，網站只會向 [FxTwitter](https://github.com/FixTweet/FxTwitter) 查詢貼文裡有哪些圖片／影片，再直接從 𝕏 的伺服器下載檔案。

**為什麼抓不到某篇貼文？**
常見原因：貼文已刪除、帳號是私人帳號、貼文裡沒有圖片，或 FxTwitter 服務暫時無法使用（稍後再試）。頁面上會顯示是哪一種。

**GIF 檔案好大？**
把 GIF 幀率或寬度調低，例如 15 fps、480 寬。如果只是要保存，直接「下載 MP4」最省空間。

**某些角色的搜尋結果很雜？**
英文名稱本身是常見單字的角色（例如 Amber、Lisa、Mona、Gaming）結果容易混雜，可以開啟「進階搜尋」或改用日文／中文 tag。
